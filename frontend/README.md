Tienda de Puntos - Frontend (Sesión 4)

Instrucciones rápidas:

1. Copiar `.env.example` a `.env` y ajustar `VITE_API_URL` si el backend no está en `http://localhost:4000`.
2. Instalar dependencias:

```bash
cd frontend
npm install
npm run dev
```

3. Abrir `http://localhost:5173`.

Endpoints usados: `GET/POST /estudiantes`, `GET /articulos`, `POST /canjes`, `GET /estudiantes/:id/movimientos`, `GET /reportes/resumen`, `GET /reportes/grados`, `GET /reportes/ranking`.
